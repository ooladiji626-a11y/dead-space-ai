# DeadSpace AI

**Live Web App:** https://dead-space-ai.vercel.app

DeadSpace AI is a 100% free, open-source browser tool that automatically detects silent gaps and removes dead space from audio files while preserving natural speech cadence for podcasts, talks, and voiceovers.

## Key Features
- **Single File & Batch ZIP Processing:** Upload individual audio files (MP3, WAV, M4A, AAC, FLAC, OGG) or full ZIP archives.
- **Smart AI Cadence Preservation:** Trims dead air without cutting off natural speech flow.
- **SRT Subtitle Generation:** Export synchronized subtitles alongside cleaned audio.
- **Client-Side Privacy & Speed:** Fast browser-based audio processing built with TypeScript, Vite, and the Web Audio API.

## Getting Started Locally
1. Clone the repository: `git clone https://github.com/ooladiji626-a11y/dead-space-ai.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
